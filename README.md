# Employee Contact Using Union in C

## Project Description

A simple C program that demonstrates the use of a union by storing either an employee's phone number or email address.

## Features

- Store phone number
- Store email address
- Display the selected contact
- Demonstrate union memory usage

## Technologies Used

- C
- Union
- Conditional Statements

## How to Run

Compile and run the `employee_contact_union.c` file using a C compiler.
